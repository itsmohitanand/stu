# STU

S3 Terminal UI 🪣

> **This is an opinionated fork of [lusingander/stu](https://github.com/lusingander/stu).** It adds functionality that suits my own workflow and is not planned for the upstream repo.

## Installation

First install Cargo (via rustup) if you don't have it:

```
$ curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

Then install this fork's `fork/main` branch:

```
$ cargo install --git https://github.com/itsmohitanand/stu --branch fork/main --locked
```
